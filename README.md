# WebTracking - Frontend

Interfaz web de usuario moderna para monitoreo y seguimiento de precios, historial cronológico interactivo (estilo Keepa), inspección visual tipo DevTools (F12) y gestión de bots de rastreo.

## Tecnologías
- **React 19**
- **Vite**
- **Lucide React** (Iconografía)
- **Vanilla CSS** con sistema de diseño personalizado

## Scripts Disponibles
- `npm run dev`: Inicia el servidor de desarrollo en `http://localhost:5173`
- `npm run build`: Genera el bundle optimizado para producción en `dist/`
- `npm run preview`: Previsualiza la versión de producción localmente
